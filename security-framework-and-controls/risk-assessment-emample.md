# Simulated Cybersecurity Risk Assessment

## Scenario

This assessment evaluates the cybersecurity risks of a fictional small business that stores customer information, processes online payments, and allows employees to access company systems.

The purpose of this exercise is to identify potential security risks and recommend controls that could reduce those risks.

## Assets to Protect

The organization needs to protect:

* Customer personal information
* Employee account credentials
* Payment information
* Company computers
* Business files and records
* Network and internet-connected systems
## Identified Risks

After reviewing the fictional organization, I identified the following potential cybersecurity risks:

| Risk                                           | Likelihood | Impact | CIA Principle Affected        |
| ---------------------------------------------- | ---------- | ------ | ----------------------------- |
| Weak or reused employee passwords              | High       | High   | Confidentiality               |
| Lack of multi-factor authentication            | Medium     | High   | Confidentiality               |
| Outdated software and missing security patches | Medium     | High   | Integrity and Availability    |
| Phishing attacks targeting employees           | High       | High   | Confidentiality and Integrity |
| Inadequate data backups                        | Medium     | High   | Availability                  |
| Excessive employee access permissions          | Medium     | High   | Confidentiality and Integrity |

## Risk Prioritization

The highest-priority risks are weak passwords, phishing attacks, and the lack of multi-factor authentication because these weaknesses could allow an attacker to gain unauthorized access to sensitive customer and company information.
## Recommended Security Controls

Based on the identified risks, I recommend the following security controls:

| Identified Risk | Recommended Control |
|---|---|
| Weak or reused employee passwords | Enforce strong password requirements and use a password manager |
| Lack of multi-factor authentication | Require multi-factor authentication for employee accounts |
| Outdated software and missing security patches | Establish a regular patch management process and enable automatic security updates |
| Phishing attacks targeting employees | Provide security awareness training and phishing simulations |
| Inadequate data backups | Perform regular encrypted backups and test recovery procedures |
| Excessive employee access permissions | Apply least privilege and role-based access control |

## Security Control Categories

The recommended safeguards include several types of security controls:

### Technical Controls

- Multi-factor authentication
- Password management
- Automatic security updates
- Role-based access controls
- Encrypted backups

### Administrative Controls

- Security awareness training
- Password policies
- Access control policies
- Patch management procedures
- Incident response procedures

## Conclusion

This assessment demonstrates how cybersecurity risks can be identified, prioritized, and reduced through appropriate security controls.

By implementing strong authentication, employee security training, regular software updates, secure backups, and least-privilege access, the fictional organization could significantly reduce its exposure to common cybersecurity threats.

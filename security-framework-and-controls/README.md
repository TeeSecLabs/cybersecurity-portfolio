# Security Frameworks and Controls

## Overview

This project documents my study of cybersecurity frameworks, security controls, risk management, and the CIA triad. The purpose of this project is to demonstrate my understanding of foundational concepts used by security professionals to protect organizations, systems, and data.

## CIA Triad

The CIA triad is a foundational cybersecurity model consisting of three principles:

### Confidentiality

Confidentiality ensures that sensitive information is only accessible to authorized users.

Examples include:

* Passwords
* Multi-factor authentication
* Encryption
* Access controls

### Integrity

Integrity ensures that information remains accurate, authentic, and reliable and is not changed without authorization.

Examples include:

* File permissions
* Hashing
* Digital signatures
* Change management

### Availability

Availability ensures that authorized users can access systems and information when they need them.

Examples include:

* Data backups
* Redundant systems
* Disaster recovery
* System maintenance

## Security Frameworks

Security frameworks provide organizations with structured guidelines for developing security plans, managing risks, and protecting information systems.

Frameworks help security teams:

* Identify security risks
* Establish security policies
* Implement security controls
* Protect organizational assets
* Respond to security incidents
* Improve overall security posture

## Security Controls

Security controls are safeguards designed to reduce specific security risks.

Examples of security controls include:

* Authentication
* Encryption
* Firewalls
* Access control
* Security awareness training
* Physical security
* Incident response procedures

I also learned that effective cybersecurity requires a combination of technical controls, policies, procedures, and employee awareness.
